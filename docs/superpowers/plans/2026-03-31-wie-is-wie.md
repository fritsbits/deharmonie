# Wie is Wie — Database-driven teamledenbeheer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vervang de hardcoded `$teams`-array in `wie-is-wie.blade.php` door een database-gedreven oplossing met een Filament resource om teamleden te beheren.

**Architecture:** Twee nieuwe tabellen (`team_categorieen` als vaste seeded data, `team_leden` als bewerkbaar). Eén Filament resource `TeamLidResource` voor CRUD op teamleden. De `PageController::wieIsWie()` methode laadt categorieën met hun leden uit de database en geeft ze door aan de view.

**Tech Stack:** Laravel 13, Filament 4, Eloquent, PHPUnit, Blade, MySQL

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

class TeamCategorie extends Model
{
    use HasFactory;

    protected $table = 'team_categorieen';

    protected $fillable = ['naam_nl', 'naam_fr', 'volgorde'];

    public function leden(): HasMany
    {
        return $this->hasMany(TeamLid::class);
    }

    public function getNaamAttribute(): string
    {
        return app()->getLocale() === 'fr' ? $this->naam_fr : $this->naam_nl;
    }
}
```

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class TeamLid extends Model
{
    use HasFactory;

    protected $table = 'team_leden';

    protected $fillable = ['team_categorie_id', 'naam', 'titel_nl', 'titel_fr', 'volgorde'];

    public function categorie(): BelongsTo
    {
        return $this->belongsTo(TeamCategorie::class, 'team_categorie_id');
    }

    public function getTitelAttribute(): ?string
    {
        $titel = app()->getLocale() === 'fr' ? $this->titel_fr : $this->titel_nl;

        return $titel ?: null;
    }
}
```
