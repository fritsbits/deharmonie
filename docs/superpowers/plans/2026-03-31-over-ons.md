# Over ons Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "pagina in opbouw" placeholder on `/over-ons` with a finished, warm page: mission story, photo strip, visitor quotes, team reference, and CTA band — fully bilingual NL/FR.

**Architecture:** Static Blade view with all copy in lang files. Quotes hardcoded in Blade (original language only — multicultural intent). No new models, controllers, or routes. Follows inline-style pattern from `diensten.blade.php`.

**Tech Stack:** Laravel 13, Blade, inline CSS with `var(--color-*)` tokens, PHP 8.4

**Spec:** `docs/superpowers/specs/2026-03-31-over-ons-design.md`
